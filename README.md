# Interpolation numérique
Ce projet porte sur l'interpolation polynomiale.

Les méthodes utilisées sont :
* Lagrange
* Newton
* Hermite

## Fonctions étudiées
1. f(x) = x²
2. f(x) = 1 / (1 + 25x²)

Pour chaque fonction, on utilise 3, 5, 7 et 9 points d'interpolation.

Le programme permet de :
* calculer les polynômes d'interpolation ;
* comparer les méthodes ;
* calculer l'erreur maximale ;
* afficher les graphiques.

## Installation
Installer les bibliothèques nécessaires :

```bash
pip install -r requirements.txt
```

## Exécution

Lancer le programme avec :

```bash
python main.py
```
